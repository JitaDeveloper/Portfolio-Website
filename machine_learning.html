    Machine Learning: কম্পিউটারকে শেখানো যায় কীভাবে?

    ধরো, তোমার কাছে একটা ছবি আছে। ছবিতে একটা বিড়াল আছে।

    তুমি ছবিটা দেখেই বলে দিতে পারো— “এটা একটা বিড়াল।”

    কিন্তু একটা কম্পিউটারকে যদি সেই একই ছবি দেখিয়ে জিজ্ঞেস করা হয়,

    “এটা কী?”

    তাহলে কম্পিউটার কিন্তু আমাদের মতো করে ছবিটা দেখে বুঝতে পারে না যে এটা একটা বিড়াল।

    তাহলে কি কম্পিউটারকে বিড়াল চিনতে শেখানো সম্ভব?

    অবশ্যই সম্ভব।

    আর এই “শেখানো”-র পিছনেই রয়েছে Machine Learning।

Machine Learning কী?

Machine Learning-এর বাংলা করলে দাঁড়ায় যন্ত্রের শেখা।

কিন্তু এখানে “শেখা” বলতে মানুষের মতো করে শেখা বোঝায় না।

আমরা যখন কোনো কিছু শিখি, তখন অভিজ্ঞতা থেকে ধীরে ধীরে একটা ধারণা তৈরি করি।

যেমন, তুমি যদি অনেকগুলো বিড়াল দেখো, তাহলে বিড়ালের কিছু সাধারণ বৈশিষ্ট্য তোমার মাথায় তৈরি হয়ে যাবে—

  • চারটি পা থাকে
  • দুটি কান থাকে
  • লেজ থাকে
  • চোখ ও নাকের একটি নির্দিষ্ট ধরনের গঠন থাকে

এরপর তুমি যদি নতুন কোনো বিড়াল দেখো, যেটাকে আগে কখনও দেখোনি, তবুও তুমি সেটাকে দেখে বলতে পারবে,

“এটা একটা বিড়াল।”

Machine Learning-এও মোটামুটি একই ধরনের একটা ধারণা কাজ করে।

আমরা কম্পিউটারকে একগুচ্ছ data দিই। সেই data থেকে কম্পিউটার কিছু pattern বা নিয়ম খুঁজে বের করার চেষ্টা করে।

তারপর সেই শেখা pattern ব্যবহার করে নতুন data সম্পর্কে prediction করে।

অর্থাৎ খুব সহজভাবে,

Data → Learning → Pattern → Prediction

এটাই Machine Learning-এর মূল ধারণা।

Traditional Programming বনাম Machine Learning

Machine Learning বোঝার আগে একটা জিনিস বোঝা খুব গুরুত্বপূর্ণ।

সাধারণ programming-এ আমরা কী করি?

ধরো, তুমি একটা calculator বানালে।

তুমি calculator-কে বলে দিলে—

“দুটি সংখ্যা নাও এবং তাদের যোগ করো।”

এখানে তুমি নিজেই নিয়মটা (rule) লিখে দিচ্ছ।

অর্থাৎ,

Input + Rule → Output

যেমন:

5 + 3 → 8

এখানে computer জানে কী করতে হবে, কারণ programmer তাকে সেই rule বলে দিয়েছে।

কিন্তু কিছু problem আছে যেখানে rule লিখে দেওয়াটা খুব কঠিন।

বিড়াল চেনার সমস্যা

ধরো, আমরা computer-কে বিড়াল চিনতে শেখাতে চাই।

তখন কি আমরা লিখতে পারি—

“যদি ছবিতে দুটি কান থাকে এবং চারটি পা থাকে এবং লেজ থাকে, তাহলে সেটি বিড়াল।”

সমস্যাটা হল, সব বিড়াল দেখতে একরকম নয়।

  • কোনো বিড়ালের লোম বেশি, কোনো বিড়ালের কম।
  • কোনো বিড়াল বসে আছে, কোনোটা শুয়ে আছে।
  • কোনো ছবিতে বিড়ালটা ছোট, কোনো ছবিতে বড়।

তাই বিড়াল চেনার সমস্ত rule আমাদের নিজেদের হাতে লিখে দেওয়া অত্যন্ত কঠিন।

এখানেই Machine Learning-এর প্রয়োজন হয়।

Machine Learning-এ আমরা অনেকগুলো example computer-কে দিই এবং বলি—

“এই data-গুলো দেখো এবং নিজে থেকে একটা pattern খুঁজে বের করার চেষ্টা করো।”

অর্থাৎ এখানে ধারণাটা অনেকটা এমন:

Data + Correct Answers → Learning → Model

তারপর,

New Data + Model → Prediction

একটা খুব সহজ উদাহরণ

ধরো, আমরা একটা computer program বানাতে চাই যেটা বলবে—

“কোনো student পরীক্ষায় Pass করবে নাকি Fail করবে।”

আমরা আগের কিছু students-এর data সংগ্রহ করলাম।

পড়ার সময় Attendance Result
2 ঘণ্টা 60% Fail
3 ঘণ্টা 65% Fail
5 ঘণ্টা 80% Pass
6 ঘণ্টা 85% Pass
8 ঘণ্টা 95% Pass

এখানে computer-এর কাছে আগের students-এর data আছে।

সে হয়তো লক্ষ্য করবে যে,

পড়ার সময় এবং attendance সাধারণত বেশি হলে Pass করার সম্ভাবনাও বেশি।

Computer এই data থেকে যে pattern শিখল, সেটাকে আমরা একটি Model হিসেবে ভাবতে পারি।

এবার নতুন একজন student-এর data দিলাম:

  • পড়ার সময়: 6 ঘণ্টা
  • Attendance: 88%

এখন model বলল:

“এই student-এর Pass করার সম্ভাবনা বেশি।”

এটাই একটি খুব সাধারণ Machine Learning problem।

তাহলে Model কী?

এখন একটা নতুন শব্দ এল—Model।

Model-কে তুমি আপাতত এভাবে ভাবতে পারো:

Model হল data থেকে শেখা একটি ব্যবস্থা, যেটা নতুন data দেখে prediction করতে পারে।

একজন student যেমন অনেকগুলো example দেখে একটা ধারণা তৈরি করে, Machine Learning model-ও অনেকগুলো data দেখে একটা pattern শেখে।

তারপর সেই pattern ব্যবহার করে নতুন data সম্পর্কে সিদ্ধান্ত নেয়।

তাই Machine Learning-এর ক্ষেত্রে আমরা বারবার তিনটি শব্দ শুনব:

Data → Model → Prediction

এই তিনটি শব্দ ভালোভাবে বুঝে ফেললে Machine Learning-এর অনেকটাই সহজ হয়ে যাবে।

Machine Learning কি মানুষের মতো চিন্তা করে?

না।

এটা খুব গুরুত্বপূর্ণ।

Machine Learning model মানুষের মতো করে “বোঝে” বা “চিন্তা করে”— এমনটা ধরে নেওয়া ঠিক নয়।

Computer মূলত data-এর মধ্যে থাকা mathematical patterns এবং relationships ব্যবহার করে কাজ করে।

আমরা বাইরে থেকে দেখলে মনে করতে পারি,

“Computer বুঝে গেছে যে ছবিটা একটা বিড়ালের।”

কিন্তু ভিতরে আসলে অনেক mathematical calculation-এর মাধ্যমে model একটি prediction তৈরি করছে।

এই কারণেই Machine Learning শেখার সময় আমরা ধীরে ধীরে Mathematics, Statistics এবং Programming-এর দিকে যাব।

তবে চিন্তা করার কিছু নেই।

Class 11–12 থেকেই Machine Learning বোঝার জন্য শুরুতেই কঠিন mathematics জানা দরকার নেই।

প্রথমে দরকার শুধু একটা পরিষ্কার ধারণা:

Computer-কে সব সময় সরাসরি rule বলে দিতে হবে—এমন নয়। কিছু ক্ষেত্রে আমরা তাকে data দিতে পারি, আর সেই data থেকে সে নিজেই pattern শেখার চেষ্টা করতে পারে।

এটাই Machine Learning-এর Basic Concept।
